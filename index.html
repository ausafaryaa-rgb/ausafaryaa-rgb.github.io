Prompting Workflow

From problem to usable AI output.

My prompting process focuses on context, clarity, iteration, and human review rather than relying on a single prompt.

01

Understand

Identify the problem, goal, audience, and required result.

02

Structure

03

Generate

04

Review

Inspect accuracy, relevance, clarity, and requirements.

05

Refine

Improve the prompt based on weaknesses in the response.

06

Finalize

Select and adapt the useful output for its intended purpose.

Prompt Examples

How I structure prompts.

These examples demonstrate a structured approach to communicating context, requirements, constraints, and expected outputs to an AI model.

Web Development Prompt Technical 
ROLE:
Act as a senior frontend developer.

CONTEXT:
I have an existing HTML/CSS website.

TASK:
Identify the cause of the rendering issue.

CONSTRAINTS:
Do not change the existing visual design.
Only modify the code necessary to fix the issue.

OUTPUT:
Provide the corrected complete HTML file.
The prompt gives the model a role, context, task, constraints, and expected output.
Content Development Prompt Creative 
ROLE:
Act as a short-form video script writer.

CONTEXT:
Create educational content for social media.

TASK:
Write a concise video script about the topic.

REQUIREMENTS:
Start with a strong hook.
Use simple Bahasa Indonesia.
Keep the pacing suitable for short-form video.

OUTPUT:
Hook
Narration
Closing
Caption ideas
The output structure is explicitly defined so the generated response is easier to review and adapt.
AI Output Review

Prompting is an iterative process.

I treat the first AI response as a starting point. The output is reviewed against the original objective before being refined or used.

STEP 01

Initial Prompt

Provide the task and relevant context to generate the first response.

STEP 02

Output Review

Check whether the response follows the requirements and intended format.

STEP 03

Prompt Refinement

Add missing context, clarify requirements, or adjust constraints.

STEP 04

Regenerate

Run the improved prompt and compare the new response with the objective.

STEP 05

Human Review

Review usefulness, clarity, accuracy, and suitability for the intended task.

STEP 06

Final Output

Adapt the useful result into the final deliverable or workflow.
